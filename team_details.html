1. Anh Tuấn Main Captain

🚀 Project Introduction

  • Project name: Knight Sudoku (Độc Mã Sudoku)
  • Core idea: A fusion of two classic algorithmic problems:
    • Knight's Tour — A knight visits all 64 squares exactly once, moving in an L-shape.
    • Latin Square — An 8×8 grid where each row and column contains digits 1→8 exactly once.
  • Goal: Complete the Knight's Tour while maintaining a valid Latin Square → WIN.

📚 Game Rules

  • 8×8 chessboard — move numbers from 1 to 64.
  • Displayed digit = (moveNumber - 1) % 8 + 1 → yields 1→8.
  • Every row and column must contain all digits 1→8 (Latin Square constraint).
  • Legal moves: knight moves in L-shape — (±2, ±1) or (±1, ±2).

🛠 Core Algorithm: Backtracking + Warnsdorff Heuristic

The Problem: Find a knight's path covering all 64 cells while satisfying the Latin Square constraint.

Backtracking:

  • Start from a cell; try all 8 possible knight moves.
  • Recursively proceed. If dead end → undo and try another direction.
  • Base case: 64 cells filled (success) OR all options exhausted (failure).

Warnsdorff Heuristic (optimization):

  • At each step, compute the Warnsdorff degree of each candidate cell.
  • Degree = number of unvisited cells reachable from that candidate (with Latin Square constraint).
  • Prioritize the smallest degree → reduces branching, accelerates search.

Latin Square Pruning:

  • rowColConflict() checks if the prospective digit already exists in the same row or column.
  • Conflict → prune that branch immediately (forward checking).

🤖 Auto-Digit Algorithm — makeMoveAutoDigit()

When the player clicks a cell in Easy mode, the computer finds a valid digit:

// Input: row, col — the cell the player just clicked // Returns: 0 = success | 1 = invalid move | 2 = no digit found makeMoveAutoDigit(row, col): if cell is occupied or not a knight jump then return 1 for digit d = 1 to 8: if d does NOT conflict with row AND column: digitBoard[row][col] = d moveBoard[row][col] = currentNumber currentNumber++ return 0 // success return 2 // no valid digit found
  • hasDigitConflict(row, col, d) scans the entire row and column for digit d.
  • This is a greedy algorithm — picks the first valid digit encountered.

⌨ Manual-Digit Algorithm — makeMoveWithDigit()

In Hard mode, the player types a digit. Validation follows:

// Input: row, col, digit (1–8 typed by player) // Returns: 0 = success | 1 = invalid move | 2 = digit conflict makeMoveWithDigit(row, col, digit): if cell occupied or not a knight jump then return 1 if digit < 1 or digit > 8 then return 1 if hasDigitConflict(row, col, digit): return 2 // conflict — tell player to try another digit digitBoard[row][col] = digit moveBoard[row][col] = currentNumber currentNumber++ return 0 // success

↩ Undo Mechanism

  • Finds the cell where moveBoard = currentNumber - 1 (non-preFilled).
  • Clears that cell's data, decrements currentNumber.
  • Re-locates the knight's new position (lastRow, lastCol).
  • Constraint: cannot undo if currentNumber ≤ 1.

handleClick(row, col): if animation is running then return if cell is preFilled then return if game is Easy mode: result = makeMoveAutoDigit(row, col) if result == 1 then return // invalid knight jump if result == 2 then // no valid digit show popup: "No 1–8 digit fits here!" return highlight valid next moves else // Hard mode if NOT isValidMove(row, col) then return show input dialog: "Enter a digit 1–8:" validate: parse int, range 1–8, row/col conflict result = makeMoveWithDigit(row, col, digit) if result == 2 then show popup: "Digit already in row or column!" return highlight valid next moves check win condition

✅ Latin Square Validation

isLatinSquareValid()

  • For each row: verify all digits 1→8 present, no duplicates.
  • For each column: verify all digits 1→8 present, no duplicates.
  • Uses an efficient boolean[9] array for O(1) lookups.

isConflictAt(row, col)

  • Checks a specific cell for conflicts with others in the same row/column.
  • Used to color cells red on the GUI in real-time.
isLatinSquareValid(): // Check all rows for each row r (0→7): boolean[] seen = new boolean[9] for each column c (0→7): d = digitBoard[r][c] if d == 0 or seen[d] then return false seen[d] = true // Check all columns for each column c (0→7): boolean[] seen = new boolean[9] for each row r (0→7): d = digitBoard[r][c] if d == 0 or seen[d] then return false seen[d] = true return true // Latin Square is valid

⚡ Auto-Solve Feature

When the player clicks "Auto Solve":

  • KnightSudoku.solveComplete() runs inside a SwingWorker (background thread).
  • The Event Dispatch Thread (EDT) is never blocked — the UI stays responsive.
  • If a solution path is found → animateSolution(path) plays it out.

animateSolution()

  • Uses javax.swing.Timer with 120 ms interval per step.
  • Each tick: fills one cell from the solution path, refreshes the board.
  • After all 64 steps → checks the win condition.
handleAutoSolve(): if animation is running then stop it new SwingWorker<int[], Void>(): doInBackground(): return KnightSudoku.solveComplete() // runs off EDT done(): path = get() if path is null then show message: "No solution found!" else animateSolution(path) animateSolution(path): timer = new Timer(120ms) for each cell in path (0→63): fill that cell refresh board highlight valid next moves check win condition
